# Admissibility Flow

## Principle

Compilation is an admissibility filter.

It does not produce truth.
It produces structural eligibility.

---

## Flow

Run Manifest
   ↓
Parsing
   ↓
Static Semantics
   ↓
Dependency Resolution
   ↓
Execution Eligibility
   ↓
Registration Eligibility
   ↓
Admissible Run Package

---

If any phase returns STOP,
the process terminates immediately.

No silent recovery permitted.
